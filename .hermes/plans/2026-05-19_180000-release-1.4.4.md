# Release 1.4.4 — seixastec_bancointer WHMCS Gateway

**Date:** 2026-05-19
**Module version:** 1.4.4
**Supersedes:** `.hermes/plans/2026-05-19_154500-bug-fixes.md`

---

## Goal

Corrigir bugs de integridade de dados e segurança encontrados na auditoria
1.4.3, e resolver a regressão principal reportada pelo usuário: boleto PDF não
estava sendo anexado em e-mails de `Overdue Invoice Notification`.

---

## Bugs Resolvidos

### BUG-2 [HIGH] — `client_secret` não mais gravado em plaintext pelo admin panel
**Opção adotada:** C (minimal) — campo removido do formulário de save; UI
exibe placeholder `••••••••` com instrução para usar Setup → Payments.
**Arquivos:** `modules/gateways/seixastec_bancointer/tools.php`

### BUG-3 [HIGH] — `generateForInvoice` só marca CANCELLED após API confirmar
`saveTransaction([..., "CANCELLED"])` movido para dentro do `try`. Falha na
API agora lança `RuntimeException` e aborta a geração da nova cobrança.
**Arquivos:** `modules/gateways/seixastec_bancointer.php`

### BUG-4 [HIGH] — DailyCronJob checa status remoto antes de cancelar
`getCollection()` é chamado antes de cada `cancelCollection()`. Status local
sincronizado. Cobranças pagas ou já canceladas na API são ignoradas.
**Arquivos:** `includes/hooks/seixastec_bancointer_auto_generate.php`

### BUG-5 [MEDIUM] — `logTransaction` key corrigida
`$params["paymentmethod"]` → `$params["name"]`.
**Arquivos:** `modules/gateways/seixastec_bancointer.php`

### BUG-6 [LOW] — Version bumps para 1.4.4
Addon admin e `whmcs.json` atualizados para `1.4.4`.
**Arquivos:** `modules/addons/seixastec_bancointer_admin/seixastec_bancointer_admin.php`, `modules/gateways/seixastec_bancointer/whmcs.json`

### BUG-7 [LOW] — Typos no `whmcs.json`
`webhoook` → `webhook`; `automática` com acento correto.
**Arquivos:** `modules/gateways/seixastec_bancointer/whmcs.json`

### BUG-9 [HIGH] — Overdue e-mails passam a receber boleto PDF em anexo
Refatoração completa do hook `EmailPreSend`:
1. **Classificação por substring** (`invoice_created` / `reminder` / `overdue` / `null`) — cobre variantes e templates localizados.
2. **Verificação de status antes da API** — não anexa se PAID ou CANCELLED.
3. **Telemetria estruturada** em todos os caminhos (outcome visível no Gateway Log).
4. **Mint on-the-fly restrito a `invoice_created`** — reminders/overdues não criam nova cobrança.
**Arquivos:** `includes/hooks/seixastec_bancointer_email_pdf.php`

---

## Bugs Descartados

### BUG-1 [CRITICAL] — Authorization header malformed
Verificado no código real: `BancoInterAPI.php:189` já continha
`"Authorization: Bearer " . $this->getAccessToken()`. Era artefato do leitor
de arquivos. **Não há bug.**

### BUG-8 [MEDIUM] — Remover overdue do hook de e-mail (INVERTIDO)
O plano anterior propunha remover `Overdue Invoice Notification` do hook.
O usuário confirmou o comportamento oposto: overdue DEVE receber o boleto.
**Substituído por BUG-9.**

## Matriz de Regressão

| # | Cenário | Esperado |
|---|---|---|
| 1 | Invoice criada com gateway Banco Inter | `Invoice Created` com PDF anexado; log `attached` |
| 2 | `Invoice Payment Reminder` (cobrança ativa) | PDF anexado; log `attached` |
| 3 | `Overdue Invoice Notification` (cobrança ativa) | PDF anexado; log `attached` ← fix principal |
| 4 | `Overdue Invoice Notification` (cobrança CANCELLED) | Sem anexo; log `skipped_cancelled` |
| 5 | E-mail em invoice PAGA | Sem anexo; log `skipped_paid` |
| 6 | E-mail em invoice de outro gateway | Sem anexo; log `skipped_other_gateway` |
| 7 | DailyCronJob — cobrança paga com webhook perdido | NÃO cancela; status sincronizado para PAID |
| 8 | `generateForInvoice` com cancel anterior falhando | Aborta com `RuntimeException`; row local NÃO marcado CANCELLED |
| 9 | Salvar config no admin sem informar `client_secret` | Outros campos salvos; `client_secret` intocado |
| 10 | WHMCS → Addons → Banco Inter | Versão exibe `1.4.4` |

## Riscos & Tradeoffs

- **BUG-3** torna falhas de cancel visíveis ao operador (antes silenciosas). Comportamento correto, porém pode expor erros previamente mascarados.
- **BUG-4** adiciona 1 chamada de API por linha por execução de cron (máx. 50/dia). Custo aceitável.
- **BUG-9 mint restrito**: invoices criadas antes do hook `auto_generate` estar ativo não receberão boleto em reminder/overdue. Operador deve gerar manualmente no painel.
- **BUG-2 Option C**: operadores não podem mais alterar `client_secret` pelo painel custom. Devem usar Setup → Payments → Banco Inter.
